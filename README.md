# Netflix Data Analysis Dashboard (Power BI)

## 📊 Project Overview
This project analyzes Netflix content using Power BI. The dataset was sourced from Kaggle and includes information about movies and TV shows such as type, country, genre, and release year.

## 📌 Key Features
- KPI cards showing total titles, movies, and TV shows
- Top 10 countries producing Netflix content
- Most popular genres on Netflix
- Content growth trend over the years
- Interactive slicer for filtering by content type

## 📈 Key Insights
- Movies dominate Netflix content
- USA produces the highest number of titles
- Rapid growth in content after 2015

## 🛠 Tools Used
- Power BI
- Kaggle Dataset
